# Real-Time Collaborative Markdown Editor

A full-stack, real-time collaborative Markdown editor built with FastAPI, WebSockets, HTML, and Marked.js.

## Features
- **Real-Time Sync**: Instant updates across connected users via WebSockets.
- **Live Preview**: Client-side Markdown rendering using Marked.js.
- **Active User Tracking**: Real-time counter of connected sessions.
- **Dark Mode**: Built-in dark/light interface toggle.
- **Export**: One-click download as a `.md` file.

## Tech Stack
- **Backend**: FastAPI, WebSockets, Python
- **Frontend**: HTML5, CSS3, JavaScript, Marked.js
